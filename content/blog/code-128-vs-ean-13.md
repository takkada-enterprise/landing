In the Code 128 vs EAN-13 choice, the answer for most distributors is both, for different jobs. EAN-13 is the 13-digit retail product code that a brand owner gets from GS1 and prints on each pack. It holds digits only, always 13 of them, and every supermarket scanner in the world reads it. Code 128 is a compact barcode that can carry letters, digits and symbols at any length, which makes it the usual pick for internal labels: a godown sticker that carries your item code and the box quantity, a part number, or a batch. If the pack already has the maker's EAN-13, use it as it is. If you are printing your own sticker for a carton, a loose item or a repacked bag, print Code 128. You only need your own EAN-13 numbers if you own a brand and sell into modern retail. Below is the side-by-side, the cases that decide it, and how the two work together at billing.

## Side by side

| | EAN-13 | Code 128 |
|---|---|---|
| Characters | Digits only | Letters, digits and symbols |
| Length | Always 13 digits | Any length |
| Where the number comes from | GS1, through the brand owner | You make it up |
| Who reads it | Every retail scanner | Any modern barcode gun or phone camera |
| Carries a box quantity | No | Yes, if your tool writes it in |
| Typical use | Retail packs on a shelf | Godown, carton and shipping labels |

## What each number actually means

An EAN-13 starts with a GS1 prefix (India's is 890), then the brand owner's company number and product number, and ends with a check digit that catches a misread. The number says "this product from this brand", worldwide. That is why you should never invent EAN-13 numbers for your own stickers: a made-up number can clash with a real product.

Code 128 has no owner and no registry. Its value is whatever your system wrote, so it can say "item 4471, 6 cartons" or "batch B2409". It also packs pairs of digits tightly, so a long number still prints in a small space.

## Which one for which job

- **Branded packs on a retail shelf:** EAN-13, from the brand owner.
- **Your own carton sticker with the quantity:** Code 128.
- **Loose stock, repacked bags, spare parts with letters in the code:** Code 128.
- **Exporting or supplying a modern retail chain under your own brand:** EAN-13, through [your own GS1 registration](/blog/how-to-get-barcode-for-products-in-india).

## How the two work together

At the billing desk, both get scanned. The maker's EAN on a single pack identifies one piece. Your Code 128 sticker on a carton identifies the item and the box quantity. A good setup reads both: the EAN linked to the item, the sticker read with its quantity.

## Frequently Asked Questions

**Q: Is Code 128 better than EAN-13?**

A: Neither is better overall. EAN-13 is the standard retail product number. Code 128 is more flexible for your own labels because it takes letters and any length.

**Q: Can I make my own EAN-13 barcodes?**

A: You can print the bars, but the number should come from GS1 through the brand owner. A made-up EAN-13 can match a real product and cause wrong scans at a retailer.

**Q: Will a normal USB scanner read Code 128?**

A: Yes. Almost every modern barcode gun reads Code 128 and EAN-13 out of the box, and so does a phone camera with a scanning app.

**Q: Which barcode should I print on cartons in my godown?**

A: Code 128, because it can carry your item code and the box quantity. Leave the maker's EAN on the packs inside as it is.
